# スクショギャラリー

Mac のスクリーンショットフォルダを、スマホの写真アプリのように一覧・拡大表示するアプリです。
`index.html` 1ファイルだけで動き、インストールは不要です。画像はブラウザの中だけで読み込まれ、どこにも送信されません。

## 使い方

1. `index.html` をダウンロードして、好きな場所に置く
2. **Google Chrome**（推奨）でダブルクリックして開く
3. 「フォルダを選ぶ」で、スクリーンショットの保存先フォルダを選ぶ

## できること

- 新しい順に、日付ごと（今日・昨日・日付）にまとめてタイル表示
- 右上のスライダーでサムネイルの大きさを変える
- タップで全画面表示し、左右スワイプ／矢印キー／2本指スクロールで前後の画像へ
- ダブルクリックやピンチで拡大し、ドラッグで移動
- 「コピー」でクリップボードへコピー（そのままチャットなどに貼り付けられる）
- Esc で一覧に戻る

## ブラウザごとの違い

| | Chrome / Edge | Safari |
|---|---|---|
| 新しいスクショの自動追加 | ○（3秒ごとに確認） | ×（フォルダを選び直す） |
| 前回のフォルダを記憶 | ○ | × |

## Dock から1クリックで開くには

Chrome で `index.html` を開き、メニューの「保存して共有 > ショートカットを作成」で
「ウィンドウとして開く」にチェックを入れると、アプリとして Dock に置けます。
